# cult-ui-svelte

A Svelte 5 / Tailwind CSS v4 port of a practical first slice of [`nolly-studio/cult-ui`](https://github.com/nolly-studio/cult-ui).

This is **not** a React wrapper. Components are Svelte-native and use runes, snippets, Svelte context, and `svelte/motion` where appropriate.

## Ported components

- `AnimatedNumber`
- `CosmicButton`
- `GlowButton`
- `GradientHeading`
- `MinimalCard` compound set
- `MockBrowserWindow`
- `DitherImage` compound set
- `Dock` / `DockItem`
- `DynamicIsland`

## Usage

### Package install

```sh
pnpm add cult-ui-svelte
```

```svelte
<script lang="ts">
	import { CosmicButton, GradientHeading } from 'cult-ui-svelte';
	import 'cult-ui-svelte/styles.css';
</script>

<GradientHeading as="h1" size="xl" weight="black">
	Build cult-grade Svelte interfaces.
</GradientHeading>

<CosmicButton href="https://svelte.dev">Launch</CosmicButton>
```

### shadcn-svelte registry install

This repo also publishes shadcn-svelte registry item JSON under `static/r/`, so components can be installed directly from GitHub raw URLs without a custom domain:

```sh
pnpm dlx shadcn-svelte@latest add \
  https://raw.githubusercontent.com/yycholla/cult-ui-svelte/main/static/r/cosmic-button.json
```

Available registry items:

- `animated-number`
- `cosmic-button`
- `glow-button`
- `gradient-heading`
- `minimal-card`
- `mock-browser-window`
- `dither-image`
- `dock`
- `dynamic-island`

Registry installs copy source into your app, normally under `src/lib/components/ui/`, and copy `cn.ts` into `src/lib/utils/cn.ts`.

If you install a component that uses shared animations, import the copied styles file from your app CSS:

```css
@import '$lib/components/ui/cult-ui-styles.css';
```

These components are Tailwind-class based. In a consuming app, use Tailwind CSS v4 and include your normal app stylesheet setup.

## Development

```sh
pnpm install
pnpm run check
pnpm run build
pnpm run build:registry
pnpm run dev
```

`src/routes/+page.svelte` is the visual showcase/smoke test. `src/lib` is the package surface. `registry.json` is the shadcn-svelte registry source; `static/r/*.json` is generated by `pnpm run build:registry` and committed so GitHub raw URLs can serve it.

## Notes on the port

- React `children` became Svelte `Snippet` props and component children.
- React Context became Svelte `setContext` / `getContext`.
- Framer Motion behavior was reimplemented using CSS transitions, Svelte runes, and `svelte/motion`.
- Next/Image usage in the original dither component became native `<img>` for framework-neutral packaging.
- Original source references are stored under `references/cult-ui-react/` for comparison.
